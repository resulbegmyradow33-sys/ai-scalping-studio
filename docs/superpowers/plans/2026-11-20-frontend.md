# Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend'in ürettiği simülasyon akışını canlı gösteren, eğitim ve performans ekranları olan Türkçe, koyu temalı Next.js panelini kurmak.

**Architecture:** Next.js App Router tek sayfa uygulaması; veri REST (SWR) + WebSocket. Grafik çizimi TradingView `lightweight-charts` ile, equity ve metrikler hafif SVG bileşenlerle. Tüm durum backend'de; panel sadece render eder.

**Tech Stack:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS v4, lightweight-charts 5, SWR 2, Vitest 3, Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-20-ai-scalping-studio-design.md`

## Global Constraints

- Arayüz dili **Türkçe**; sayılar `tr-TR` biçiminde (`2.350,00`), tarih `DD.MM.YYYY HH:mm`.
- Koyu tema varsayılan; açık tema v1'de yok.
- Renkler: kâr `#16A34A`, zarar `#DC2626`, nötr `#94A3B8`, vurgu `#3B82F6`.
- Her simülasyon/performans ekranında "Gerçek para değil / veri kaynağı: sentetik" etiketi görünür.
- Panel backend yokken çökmemeli: her ekran iskelet (skeleton) ve hata durumu gösterir.
- `NEXT_PUBLIC_API_BASE` varsayılan `http://127.0.0.1:8000`.
- Erişilebilirlik: tüm kontroller klavye ile kullanılabilir, `aria-label` var, kontrast AA.
- **Her UI görevinden önce** `modern-web-guidance` skill'i çağrılır (native `<dialog>`, container queries, `prefers-reduced-motion` gibi güncel kalıplar için).
- Sır yok; sadece `NEXT_PUBLIC_*` değişkenleri.

- [ ] **Step 3: Implement**

`createSequenceGate()` keeps last seen, a `Set` of pending, and `resumeFrom`. `useSimulation` opens `ws://.../ws/sim`, on open sends `{type:"resume", seq: gate.resumeFrom - 1}`, dispatches messages to state via `useReducer`, reconnects with backoff `500,1000,2000,4000` capped at 8s, and stops reconnecting on unmount. On `episode_end` sets status `"finished"`.

**Session epochs:** the server resets `seq` to 0 on every start/reset and announces a new `session_id` in the `status` payload. When a `status` message carries a `session_id` different from the last one seen, the client must **reset the gate to `head_seq`** (and clear bars/trades/equity), otherwise the new session's low `seq` values are rejected as stale and the chart freezes.
